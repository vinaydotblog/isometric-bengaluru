# Isometric Bengaluru

Four isometric data pieces about Bengaluru, plus a Delhi Metro companion map.

- **Concrete Tide**: land cover 1973–2020 (three.js WebGPU + TSL)
- **Namma Metro, Layered**: the metro network since 2011, with a customise panel
- **Monsoon Almanac**: IMD climate normals 1991–2020 (hand-projected SVG)
- **Lakhs of People**: census population 1941–2011 (Canvas 2D)
- **Delhi Metro, Layered**: the same metro engine at Delhi's scale

Static site: open `index.html` through any web server. three.js and fonts load from public CDNs.

## Sources

- Land cover: T.V. Ramachandra et al., Energy & Wetlands Research Group, IISc, ENVIS Technical Report 131
- Namma Metro: BMRCL figures via Wikipedia
- Climate: India Meteorological Department normals 1991–2020, via Wikipedia
- Population: Census of India, via Wikipedia
- Delhi Metro: station order and positions © OpenStreetMap contributors (ODbL); opening dates and layouts from Wikipedia's list of Delhi Metro stations
